Set a script to be run on a node before the job can run on it. If the script returns a non-zero exit code, the node will be vetoed for job execution, and either another node will be chosen, or the job will be sent back to the build queue waiting for an available node that matches its prerequisites.

The following environment variables are available in the prerequisite script:

NODE_NAME
The name of the node (e.g. agent-01, Built-In).
NODE_HOSTNAME
The hostname of the node as reported by the operating system.
NODE_IP
The IP address of the node.
NODE_LABELS
Space-separated list of labels assigned to the node.
