Maximum number of retry attempts when a system-level prerequisite check fails. After each failure, the check will be retried after the configured retry interval. Once a retry passes, the node is accepted and the queued task can execute on it.

Set to 0 to retry forever (no limit): the queued task keeps waiting until the check passes. This is the default.

This setting only applies to system-level prerequisite rules. Job-level prerequisite checks always retry forever with a fixed 60 second interval.
