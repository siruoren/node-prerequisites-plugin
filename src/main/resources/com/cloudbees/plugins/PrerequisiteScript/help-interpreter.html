Command interpreter used to execute this script on the target node.
  • Shell Script – runs the script with sh (Linux/macOS agents)
  • Windows Batch Command – runs the script with cmd /c (Windows agents)
  • Groovy Script – evaluates the script in a Groovy sandbox on the agent via Jenkins Remoting (the Groovy Sandbox checkbox still applies)
For Shell/Batch the script runs as a process on the node; for Groovy it runs inside the agent JVM. Each script within a rule can use a different interpreter.
