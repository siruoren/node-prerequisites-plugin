Fuzzy pattern to match node names. The script will only execute on nodes whose name matches this pattern. Supports the following wildcards:
  • * – matches any sequence of characters
  • ? – matches any single character
Multiple patterns can be specified as a comma-separated list; a node matching any pattern will be included.

Examples:
  • * – all nodes (default)
  • build-* – nodes starting with build-
  • agent-1,agent-2 – only agent-1 and agent-2
  • *-linux,*-mac – nodes ending with -linux or -mac
  • worker-? – worker-1 through worker-9
