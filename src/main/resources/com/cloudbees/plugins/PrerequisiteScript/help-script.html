The prerequisite script to run. Its meaning depends on the Interpreter selected above:
  • Groovy Script – a Groovy script evaluated in a sandbox on the target node (not the controller) via Jenkins Remoting. It must return true to pass, or false to block the node. Available bindings:
    • NODE_NAME – node name (String)
    • NODE_HOSTNAME – hostname resolved on the node (String)
    • NODE_IP – IP address resolved on the node (String)
    • NODE_LABELS – space-separated labels (String)
  • Shell Script / Windows Batch Command – the script runs as a process on the target node. It must exit 0 to pass. The same values are exposed as environment variables (NODE_NAME, NODE_HOSTNAME, NODE_IP, NODE_LABELS).

Groovy example: 
// Check disk space on the node itself
def root = new File('/')
def free = root.getFreeSpace() / (1024 * 1024 * 1024)
println "Free space on ${NODE_NAME}: ${free}GB"
return free > 10
Shell example: 
#!/bin/sh
free=$(df -P / | awk 'NR==2 {print $4}')
test "$free" -gt 10485760
