The Groovy script runs inside a compile-time sandbox based on SecureASTCustomizer, regardless of this checkbox (the checkbox is kept for configuration compatibility).
Blocked at compile time (the script fails with a SecurityException and the check counts as failed):
  • explicit imports outside the safe whitelist (e.g. java.lang.Runtime)
  • method calls on System, Runtime, Thread, ClassLoader, Class, ProcessBuilder, Process, Eval, GroovyShell

Known limitations of the groovy-2.4 sandbox: process spawning via "command".execute(), new ProcessBuilder(...) and dynamic-receiver reflection are not blocked. If you need to run commands, use the Shell Script / Windows Batch Command interpreter instead; for hard sandboxing install the Jenkins script-security plugin.
