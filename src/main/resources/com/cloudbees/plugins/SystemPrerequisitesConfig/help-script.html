A Groovy script to evaluate whether the node meets this system prerequisite. Runs on the target node (not the Jenkins controller) in a Groovy sandbox. The script is sent to the agent via Jenkins Remoting.

The script must return true if the node passes the check, or false to block the node.

Available bindings:
  • NODE_NAME – node name (String)
  • NODE_HOSTNAME – hostname resolved on the node (String)
  • NODE_IP – IP address resolved on the node (String)
  • NODE_LABELS – space-separated labels (String)

Example: 
// Check disk space on the node itself
def root = new File('/')
def free = root.getFreeSpace() / (1024 * 1024 * 1024)
println "Free space on ${NODE_NAME}: ${free}GB"
return free > 10
