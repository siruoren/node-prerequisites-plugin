Define system-level prerequisite rules that run on the target node via Jenkins Remoting, before job-level prerequisites.

Rules default to Groovy sandbox execution. Each rule can target specific nodes by label matching or name regex. The script receives these bindings:
  • NODE_NAME – the name of the node
  • NODE_HOSTNAME – hostname resolved on the node
  • NODE_IP – IP address resolved on the node
  • NODE_LABELS – space-separated labels assigned to the node
Return true to pass, false to block the node.
