A script to be executed on the node. If it returns a non-zero exit code, the node will be vetoed from hosting the build.

The following environment variables are available in the script:
  • NODE_NAME – the name of the node
  • NODE_HOSTNAME – the hostname reported by the OS
  • NODE_IP – the IP address of the node
  • NODE_LABELS – space-separated labels assigned to the node

Example (shell):
echo "Checking node: $NODE_NAME ($NODE_IP)"
test -f /usr/bin/docker || exit 1

Example (groovy):
println "Checking node: ${System.getenv('NODE_NAME')} (${System.getenv('NODE_IP')})"
def docker = new File('/usr/bin/docker')
if (!docker.exists()) System.exit(1)
