Maximum time in seconds to wait for a prerequisite check script to complete. If the check exceeds this duration, the process is killed to prevent zombie process accumulation, and the node is blocked.

This timeout applies to both:
  • System-level Groovy sandbox scripts (executed via Remoting)
  • Job-level Shell/Batch/Groovy scripts (executed via Launcher)
Set to 0 to disable timeout (not recommended).
Default: 60 seconds
