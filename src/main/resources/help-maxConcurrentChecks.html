Maximum number of prerequisite checks (system-level and job-level) that may run at the same time. All checks share one queue: when the limit is reached, further checks are queued and executed one by one in scheduling order (first-come-first-served).

Set to 0 to disable the limit (every check starts immediately).

Note: system-level checks on the same node are always serialized (one at a time, in scheduling order), regardless of this limit — multiple rules matching one node, or several queued tasks landing on the same node, will not run their system checks concurrently.
Default: 4
