Maximum number of prerequisite checks (system-level and job-level) that may run at the same time on a single node. Each node has its own limit: when the limit is reached on a node, further checks for that node are queued and executed one by one in scheduling order (first-come-first-served), while checks on other nodes are unaffected.

Set to 0 to disable the limit (every check starts immediately).

Note: per-node ordering always applies regardless of this limit — on each node, system-level checks run one at a time (in scheduling order, even when triggered by different queued tasks), and a job-level check on that node only starts after all system-level checks have finished.
Default: 4
